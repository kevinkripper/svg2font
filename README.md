# SVG2Font

A simple tool for turning SVGs into OpenType fonts, inspired by [Glyphter](https://glyphter.com/).

Drop `.svg` files into a character grid, preview your font, and download an `.otf`.

## 
→ [Try it here](https://kevinkripper.github.io/svg2font/) or download the index.html and run it locally.
##
## Features

- **Drag & drop SVGs** directly onto character cells.
- **Import multiple SVGs at once.** SVG2Font automatically assigns them to characters based on their filenames.
  - `A.svg` → A
  - `b.svg` → b
  - `7.svg` → 7
- **Move glyphs between characters** by dragging them from one cell to another.
- **Uppercase / lowercase linking.** Use the same glyph for `a` and `A`, or keep them independent.
- **Common characters** can be shown or hidden to keep the character map compact.
- **Add custom characters**, including accented letters, symbols, and other Unicode characters.
- **Add multiple custom characters at once** by separating them with commas.
- **Live font preview** before exporting.
- **Export directly to OpenType (`.otf`).**
- **Save and load projects** so a font can be edited later.
- **And more!**
